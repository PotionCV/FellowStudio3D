# Reusable poses

Carry, Aim, Guard and Crouch contain pose channels only. Add a Pose layer, choose
Load pose, select an affected region and adjust Mix / Keep base swing.
Capture current pose stores a frame; Save pose exports your own small JSON.
For lower-body crouching, enable Keep ground contact on the pose layer.
No model, textures, camera or local paths are copied into pose resources.
