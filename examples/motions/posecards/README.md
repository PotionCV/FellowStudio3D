# Pose-card performances / 姿势卡表演 / ポーズカードの動作

Open these through **Motion examples…** to keep your current character.
Choose **Edit base motion → Edit pose cards…** to change the cards.

- **SideStepDance**: a looping, mirrored groove with different transition speeds.
- **GuardSignal**: glance from a guard pose, then raise an arm and hold the signal.
- **ShyGreeting**: look away, glance back and make a small greeting before settling.

Cards can be edited, mirrored or replaced with your own saved poses. Grounding
aligns foot height; it does not guarantee planted feet or collision-free motion.
Rebuild only these examples with `python tools/build_pose_animation_examples.py`.

中文：用“动作案例…”载入，保留当前角色；在“调整基础动作 → 编辑姿势卡…”中
继续修改。三套示例分别展示循环舞步、防守后发出信号、害羞地打招呼。

日本語：「動作サンプル…」から読み込むと現在のキャラクターを保持します。
基本動作の「ポーズカードを編集…」からカードを編集できます。
