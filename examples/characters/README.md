# Character examples

Open these files using the main window's Open button.

To try only the character appearance in your existing animation, use Character
model > Load model and select ../models/CustomModel.json, then Apply model.

- `DefaultCharacter.json`: default model and default UV textures.
- `CustomCharacter.json`: a curated painted character with matching model,
  embedded textures and pixel protection groups.

Both use neutral idle motion. They do not contain UI preferences, source-image
paths or the author's working motion edits. Opening an example does not change
the example file; use Save to keep your own version. New installations still
start with the default character, not CustomCharacter.

The curated CustomCharacter and CustomModel share the same updated model,
painted PNGs and pixel protection groups. Appearance changes do not replace
the neutral example animation or introduce local file dependencies.
