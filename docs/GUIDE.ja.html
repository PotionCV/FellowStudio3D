1. 起動とサンプルキャラクター

Windows ポータブル版の ZIP をすべて展開し、FellowStudio3D.exe をダブルクリックします。Python のインストールは不要です。EXE、runtime などのファイルは同じフォルダー構成のまま使用してください。BAT は代替の起動方法です。このパッケージは Windows 用で、macOS では直接実行できません。

右上のメニューで英語・簡体字中国語・日本語を切り替えられます。選択は保存されます。A− / A＋ で UI の大きさを変更できます。左右のパネルはスクロールでき、境界をドラッグすると幅を変更できます。使い方または F1 で、このガイドをオフラインで開けます。

自動生成されるプロジェクト名は UI の言語に関係なく英語（Idle、Walk、Run）です。自分で入力した名前は維持されます。

最初は次の手順をお試しください。

  1. 制作ライブラリ… → キャラクターでくまモン（個人ローカル版）またはペイントキャラクターを選びます。
  2. 動作で歩行・水泳・自分の動作を選び、四方向で再生します。
  3. 組み合わせを適用し、編集ツールはアニメーションを作成…から開きます。
  4. プレビューをクリックして対象のビューを選び、1x の PNG 横並び画像を書き出します。

DefaultModel.json で標準の外観に戻せます。初回起動では標準の人形が表示され、開発者の個人作業データは読み込まれません。

制作ライブラリ：組み合わせて確認してから適用

制作ライブラリ…は従来の動作サンプルのファイル選択に代わる入口です。動作／キャラクターを切り替え、カテゴリや中国語・英語・日本語の名前、ファイル名で検索できます。swim、Kumamon、MyMotionなどを試してください。結果がなければ検索を消します。検索とタブの切り替えでは選択中の組み合わせは変わりません。

動作を選ぶと選択中のキャラクターで試し、キャラクターを選ぶと動作を保持します。右の概要に両方の名前と秒数／FPSを表示します。四方向の再生、時間バー、ダブルクリックによる単一ビュー拡大を使えます。プレビューはバックグラウンドで生成し、古い要求は取り消します。全体のプレビューが成功すると組み合わせを適用でき、1回で元に戻せます。キャンセルはプロジェクトを変更せず、選択をリセットは入ったときの外観と動作へ戻します。

ファイルを読み込む…では自分のモデルや動作を適用前に試せます。標準一覧は登録済みの公開サンプルだけを使い、個人の保存データは検索しません。キャラクターモデル → キャラクターライブラリ…は編集中のモデル草稿に外観を選びます。外側のモデルを適用で確定し、キャンセルですべて破棄できます。従来のモデルファイル読み込みも残っています。

標準一覧は標準モデル・描画済みモデル・一体型マスコットの3種類に整理しました。似たしっぽ・装備・表情の派生モデルは外しました。くまモンと猫は元の描画のまま個人ローカル版の自分のキャラクターに含め、公開版には含めません。

動作の保存と移行：アニメーションを作成… → アニメーションを保存…は基本動作・レイヤー・ポーズ・しっぽ・調整・物理を保存し、外観は含めません。標準保存先はローカルのuser_data/motionsで、ライブラリの自分のアニメーションに表示します。別のキャラクターへ適用してもモデル・描画・表示設定を保持します。上部の保存は完全なプロジェクト用です。

しっぽの骨と動作：モデル画面では外形を設定します。適用後は全体調整のしっぽから根元・中間・先端を選び、上下・左右・ひねりを調整します。四方向の関節ハンドルもドラッグできます。しっぽ動作は影響度・時間・フェード・合成に対応し、ポーズカードにも3関節を保存します。3関節FKと連続スキニングに加え、物理追従で根元・中間・先端の柔らかさと反発を調整できます。標準は0、最初は0.2／0.45／0.65を試してください。設定は動作に保存され、プレビューと出力で同じ計算を使います。衝突判定はありません。

手持ちの物は直方体・円柱・球・円錐から作り、形と描画で用途を決めます。武器だけに限定しません。形状・寸法・持ち方を変更でき、独立UVとピクセル保護を保持します。旧武器モデルは読み込めますが、標準一覧からは外しました。

2. キーフレームを使わないポーズと動作

左側で基本動作またはプリセットのポーズを選びます。基本動作の編集では、歩幅、腕振りなどのパラメーターを調整できます。長さ、フレームレート、繰り返し回数によって、出力するフレーム列が決まります。

身体の部位を選ぶと、その動作全体に対する姿勢を調整できます。まず両腕・両脚をまとめて調整し、片側を選んで細かく直します。振れ幅は平均姿勢の周りの動きを変えるもので、すべての角度を単純に拡大するものではありません。

動作をレイヤーとして追加し、混合の割合で影響を調整します。割合がゼロなら、そのレイヤーは影響しません。腕を上げる動作や手を振る動作では、元の揺れを残す量も調整できます。例えば走行に右腕を上げる動作を重ね、混合と元の揺れの保持量を調整すると、腕を上げたまま走行の腕振りを残せます。レイヤーの有効・無効や適用する部位も選択できます。

基本動作を切り替えると、動作の調整値はその基本動作の初期値に戻ります。モデル、テクスチャ、表示設定は維持されます。調整済みの組み合わせを残すには、切り替える前にプロジェクトを保存してください。Ctrl+Z で元に戻し、Ctrl+Y でやり直せます。

動作をつなぐ…では1〜6個の動作をキーフレームなしで配置できます。動作を追加し、選択した行を上下に移動・削除して、動作ごとのフレーム数とつなぎ方を選びます。適用前に総フレーム数とFPSを表示します。作成時はキャラクター・基本動作・姿勢設定を保持し、重ねる動作を編集可能な通常レイヤーに置き換えます。元に戻すこともできます。全体を1回再生し、歩行・走行の周期は保ちます。各動作の間は基本姿勢へ戻る方式で、連続技の重心・接触を自動で解く機能ではありません。examples/motions/sequences の3つのサンプルを試してください。

泳ぐはループ動作です。泳ぎ方 → 平泳ぎ／クロール／立ち泳ぎを選び、腕のかき幅、キック、浮き沈み、姿勢を調整します。体のロールはクロールのときだけ表示します。浮遊では高さ、浮き沈み、腕の広がり・羽ばたき、膝曲げ、前後の傾きを調整できます。重ねる動作としても使用でき、地面の攻撃を重ねても浮遊の高さを保持します。頭の動きや片腕の手振りを追加でき、空中姿勢には呼吸の足固定を適用しません。柔らかさも引き続き使用できます。水面・浮力シミュレーション・翼の形状を生成する機能ではありません。examples/motions/game の SwimBreaststroke・SwimFrontCrawl・TreadWater・Hover と、fusions の HoverWave・FloatingMage・SwimLookAround を試してください。

ポーズアニメーション…では2〜6枚の自作ポーズカードから動作を作れます。カードを選び、4つのビューで手足をドラッグするか、部位を選んで角度を調整します。基本ポーズ、保存したポーズ、元の動作のフレームからカードを追加できます。複製・左右反転・並べ替え・削除に対応します。各カードの保持拍数・次への補間拍数と滑らか／等速／きびきびの補間を設定します。拍は相対的なタイミング、長さは全体の秒数です。ループは最後から最初へ補間し、1回再生／末尾保持は最後のカードで終わります。

カード表示は元のポーズ、再生はレイヤーと全体調整を含む結果です。新規作成ではキャラクター・画像・構図を保持し、取得した姿勢に調整を含めて旧レイヤー・調整・物理をリセットします。既存のポーズ動作の再編集ではレイヤーと全体調整を保持します。適用は1回で取り消せ、キャンセルではプロジェクトを変更しません。通常のレイヤー・物理を追加でき、基本動作のポーズカードを編集…から再編集できます。接地は足底の高さを合わせます。空中動作では無効にしてください。関節値の補間なので、足運び・衝突・足位置の固定を自動計画しません。交差や滑りを再生して確認してください。長さは2〜120フレームです。examples/motions/posecards の SideStepDance・GuardSignal・ShyGreeting を試してください。

既存のポーズ動作を再編集するとき、「基本動作のフレーム」は基本ポーズだけを取得します。レイヤーと全体調整を別に保持し、取得後の二重適用を防ぎます。

3. 頭部・胴体・IK・物理追従

方向のあるスライダーで負値を使えるようになりました。前屈を後屈に変えたり、うなずき・首振り、腕の前後、肘、手の間隔、歩行の腕振り・ひねり、攻撃の体の連動を逆にできます。全体操作の振り幅が負なら平均姿勢を中心に反転します。前後方向の関節曲げで肘・膝を個別に調整できます。しゃがみの脚の開閉は正で外側、負で内側、0 で従来の姿勢です。examples/motions/game/LeanBack.json と WideSquat.json を試してください。時間・回数・寸法・物理追従の強さは有効範囲を保ちます。

標準の突きは小さな体の連動です。準備時に肩を約 10° 逆にひねり、打ち出すときに肩を約 22°、骨盤を約 10° 回します。カメラ方向ではなく、元の構えからの変化量です。大きく回す場合は体の連動を増やすか、腰ひねりを重ねてください。

突きと振り攻撃は、溜め動作の大きさと溜め時間を別々に設定できます。肘と拳を引き、肘を曲げ、胸と骨盤を攻撃と反対にひねってから打ち出し、元の構えに戻ります。大きさを 0 にすると準備動作を省けます。時間は準備のテンポを調整します。両方の攻撃は調整済みの構えから始まり、攻撃後に構えのオフセットを重ね直しません。

腰ひねりは胸と骨盤をひねって元の姿勢に戻ります。負の角度で反対側にひねり、「骨盤の追従」で腰の回転割合を調整します。構えや攻撃に重ねられます。突き・振り攻撃・キックの体の連動を強め、範囲を 0–3 に拡張しました。新しい攻撃は骨盤を含む関連部位に作用します。腕・脚のマスクを指定すれば作用範囲を制限できます。既存の攻撃レイヤーで体全体を連動させるには、作用部位を関連部位に変更してください。

腕を上げる → 方向 → 前へで、前方への手伸ばし、持つ姿勢、頭上への挙上ができます。高さと肘の曲げを別々に調整できます。横方向も選択でき、既存のレシピの方向は変わりません。

拾う・置くは地面へ手を伸ばして持ち上げ、最後の姿勢を保持します。地面に置く方向では逆の順序になります。左右・両手、かがみ、しゃがみ、両手の間隔、高さ、肘の曲げを調整できます。高さは 180° まで設定でき、高く上げるほど肘を伸ばします。腕が長く脚が短い体型では、手が地面を押して足が浮かないように、かがみ・しゃがみを調整します。物のモデルは追加されません。最後の持つ姿勢には最終フレーム保持を使います。examples/motions/ 内の game/Pickup.json、game/PutDown.json、game/LiftOverhead.json、fusions/CombatTwist.json、fusions/CombatPushKick.json、fusions/ForwardCarry.json を試してください。

Kick の キックの種類で、従来の振り上げキックと前蹴りを選べます。前蹴りは膝を上げ、前に伸ばし、脚を畳んでから下ろします。左右・両脚とタイミングの設定も使えます。examples/motions/game/PushKick.json を試すか、ジャンプのキックレイヤーで前蹴りを選択してください。

ジャンプや弾む動作の空中区間では、ポーズ・動作レイヤーが空中状態と高さを引き継ぎます。置換などの合成でも、キック・被弾・転倒・旋回・接地ポーズによって地面へ戻されません。ジャンプより前に動作レイヤーを置いた場合も同じです。明示的な地上ローリングは接地を強制します。examples/motions/fusions/JumpKick.json は空中キックの例です。

突きは調整済みの構えから腕を伸ばし、元の構えへ戻ります。構えの肘曲げを攻撃の後に再加算しません。伸ばす段階では腕を固め、戻す段階で通常の物理追従へ戻ります。examples/motions/fusions/CombatStraightPunch.json を試すか、CombatStanceへ突きを追加してください。

待機の呼吸では脚を少し曲げて戻し、足の位置をIKで保ちます。上半身のポーズや脚の物理追従と組み合わせても固定されます。体の調整時に足を固定する設定を解除すると足も動きます。ジャンプ中の足を地面へ引き戻すことはありません。

少し横を向いた戦闘姿勢には、胴体の全身の向きを1°単位で調整し、胸と骨盤を別々にひねります。骨盤の回転は胴体下部と脚の付け根に作用するため、64pxでは小さい角度の差が見えにくい場合があります。examples/motions/fusions/CombatStance.json は呼吸を保ち、胸と骨盤をずらして頭を前へ向けた防御姿勢の例です。

プレビュー下の総フレーム数（1～120）を入力し、Enter またはフォーカス移動で確定します。FPS は再生速度です。24フレーム・12FPSなら2秒です。FPSを変更してもフレーム数は維持されます。基本動作の繰り返し回数で、列の中に何周期入れるかを決めます。

プレビュー上の画面 Y (px) は元画像のピクセル単位で構図を移動します。正で下、負で上です。全ビュー、IKハンドル、書き出しに反映され、動作の切り替え時も保持されます。ワールド内の位置は変わりません。キャンバスより高いモデルは、移動だけでは収まりません。

テクスチャを表示と部位の色分けは独立しています。テクスチャを消しても色分けを表示でき、両方を消すと白いモデルになります。色分けだけを消しても描いた画像は残ります。新規レイヤーの初期合成は変化の加算です。開始位置と終了位置は列全体の0～1の位置で、終了は開始より後に設定します。

走行・ジャンプ・ローリングを重ねると空中回転を作れます。基本動作に従う接地方法では、ジャンプの軌道を保ちます。地上ローリングは接地を強制し、空中回転は接地を解除します。開始と終了を空中の区間に合わせてください。examples/motions/fusions/RunJumpRoll.json は画面Y=8の例です。すでに構図を設定した場合は、その値が維持されます。非ループの物理追従は親骨格のワールド回転にも反応します。最終フレームでは停止するため、動作の途中を再生して確認してください。

再生方法はループ・1回再生・最後の姿勢を維持から選べます。非ループ動作は最終ポーズまで再生して停止し、GIF も一度だけ再生します。倒れる動作は倒れたポーズを保持し、起き上がりは立ち姿で終わります。物理追従も終点を始点へ循環させません。

制作ライブラリ… → 動作は現在のモデル・画像・表示を保持して動作設定をプレビューします。game にはジャンプと着地、突き、振り攻撃、キック、被弾、倒れる、起き上がる、ローリング、登るループ、その場で振り向く動作があります。攻撃には溜めと攻撃の時間、ジャンプには準備・空中・着地の段階があります。被弾の回復量をゼロにすると反応後の姿勢を維持します。歩行・走行の移動方向で横移動・後退を作り、足の間隔と支持時間も調整できます。

ポーズレイヤーを追加すると現在の姿勢を取得します。examples/poses の Carry・Aim・Guard・Crouch を読み込むか、自分のポーズを保存できます。部位、混合率、元の揺れの保持量を選びます。手振りと攻撃は左右・両側、同期・交互に対応します。タイミングと合成では開始位置、終了位置、フェード、合成方法を調整します。姿勢と動きは姿勢の中心と揺れを分け、置換は選択部位を動作へ合わせ、加算は標準姿勢からの差を重ねます。1回再生のレイヤーは区間後に外れ、最後の姿勢を維持は最終ポーズを保持します。短い動作には置換を使い、接続を確認してください。fusions に組み合わせの例があります。現在の動作を残したい場合は、サンプルを読み込む前に保存します。

頭部では、うなずき、左右の回転、傾き、前後位置を個別に調整できます。胸の回転に追従する設定をオフにすると、胸の左右回転を頭に引き継がなくなります。歩行と走行には、胸と骨盤を逆方向に回すストライドのひねりもあります。

胴体では、前後の曲げ、高さ、左右の傾き、胸と骨盤の回転を調整できます。胴体の調整時に足の位置を維持する設定をオンにすると、脚の届く範囲内で IK が足の位置を保持します。一時停止して表示中の IK ハンドルをドラッグすると、手足を調整できます。目標位置に届かない場合は、手足の長さを確認するか、移動量を小さくしてください。肘・膝の曲がる方向も反転できます。

上側と下側の柔らかさは、それぞれ物理追従を調整します。まず小さい値から試してください。強すぎると意図したポーズが崩れる場合があります。調整直後は直接指定した姿勢が先に表示され、物理計算と残りのフレームが後から更新されます。動作全体を判断するときは、計算の完了を待ってください。

4. ビューとピクセル表示

標準の描き込み風は大きな明暗の色面と控えめなハイライトを使い、三角面の細かい陰影を避けます。従来の立体的な表示も選べます。照明とセルフシャドウは切り替え・強さとも独立し、照明を0やオフにしても影を残せます。光源の方向と高さは共通です。

ビュー上部のキャンバスサイズ…で幅と高さを32〜256ピクセルの範囲で個別に変更できます。モデルやUV画像を拡大せず、水平中央と下余白を保って画面を広げます。全プレビューと出力に同じ設定を使います。小さいプレビューでは最近傍縮小を使いますが、出力は元のピクセルと整数倍拡大を保持します。

メイン画面の画像表示と同じ場所で照明とセルフシャドウを切り替え、別の光源設定…で3D空間での光の方向・高さ・強さ・光と影の色を調整します。ぼかしや連続グラデーションを使わず段階的に明暗を付け、元PNGと保護グループは変更しません。即時プレビューと元に戻すに対応し、プロジェクトに保存します。動作の移行時は対象の画面と光源を保持します。旧プロジェクトは64×64・照明なしのままです。大きな出力はアトラスを分割し、極端に大きなGIFには倍率やフレーム数の削減を案内します。

4つのビューのいずれかをクリックして、対象のビューを選択します。正面と側面は正投影です。斜めビューは水平の斜め視点で、俯瞰ビューでは見下ろす角度が加わります。モデルと UV の編集では、単一ビューまたはビューのダブルクリックで拡大できます。変更前の比較ボタンを押している間は、編集画面を開いた時点の外観を確認できます。

元の画像は 64 × 64 ピクセルです。プレビューを拡大しても描画の細かさは増えません。輪郭線は常に元画像の 1ピクセルで、色または自動のグレーを選べます。部位の色分け、重なりの隙間、輪郭線は独立した表示設定です。接続部などの実体が交差する場所では内部線を抑え、手前の部位が奥を隠す場合は境界線を残すことがあります。

5. モデルの形を調整する

キャラクターモデルで部位と基本形状を選び、比率を調整します。頭部には楕円体、円柱、角丸の箱、箱があります。胴体や手足にも複数の形があります。左右の連動をオンにすると、左右の手足を同時に変更できます。

肩幅、ウエスト幅、腰幅は正面の輪郭を変えます。胴体の厚みは前後方向の厚さを変え、骨盤にも適用されます。少しがっしりさせるなら 1.15～1.3 から試してください。新規モデルは 1.15、旧モデルは元の厚みを維持します。頭部の間隔と前後位置、手足の長さ、関節の位置、接続間隔も調整できます。負のオフセットは内側・重なり、正は外側・離れる方向です。骨盤のカバー量で脚の付け根の間を埋められます。

変更はプレビュー段階では確定しません。モデルを適用で確定し、キャンセルで未適用の変更を破棄します。モデルを保存では形状、埋め込み画像、ピクセル保護グループを1つの JSON に保存します。モデルの読み込みは現在の動作を維持して外観を変更します。形状だけを含む旧プリセットでは、現在のテクスチャを維持します。

頭部 → 耳から人の耳・猫耳・長い耳を左右ペアで追加できます。耳を選択して耳の形状を編集を開くと、左右・上下・前後の位置、根元の幅、長さ、厚み、先端の幅、3方向の回転を調整できます。位置は形状調整後の頭部に対する比率、寸法は元画像のピクセル単位です。左右の連動を解除すると個別に編集でき、片耳または両耳を削除できます。耳は頭部の動きに固定して追従します。モデルを適用後、UV画面に耳のカードが追加されます。右耳は初期状態で左の画像を共有し、共有を解除すると個別に描けます。形状・画像・保護グループはモデルやプロジェクトに保存されます。既存の描画フォルダーに耳がない場合は、調整した描画コピーを作成して新しいPNGを追加してください。

体の構造 → 一体型マスコットを選ぶと、頭と胴体が1つの本体パネルになります。全体の高さ、上部の幅、お腹の幅、底部の幅、厚みの5項目を調整します。頭頂からお腹まで連続した形で、首の継ぎ目はありません。手足と耳は独立しています。初期状態では頭と体を一緒に動かすがオンです。解除すると頭部の動きで上部を柔らかく回転でき、柔らかさも調整できます。胸、骨盤、手足、IK、既存の動作は引き続き使えます。UV画面では頭と胴体の代わりに本体のカードを1枚表示します。モデル保存には形状、画像、保護グループが含まれます。構造を切り替えると本体のUV配置が変わるため、新しい描画フォルダーを用意してください。examples/models/PlushModel.jsonは未描画の開始モデルです。従来の分離型モデルの形状とUVは維持されます。

6. テクスチャを描く・差し替える

部位の画像をクリックしてUV画面を開きます。PNGを保存…で元の画像を保存し、画像をコピー (Ctrl+C)／貼り付けて置換 (Ctrl+V)で描画ソフトと画像を交換できます。元のサイズと透明度を保持し、グリッド・選択範囲・ガイドは含めません。貼り付ける画像は現在のUVと同じサイズが必要で、自動縮小はしません。保護グループは保持します。元に戻す・キャンセルが可能で、画像を適用すると親の編集画面に反映します。古い描画ファイルによる上書きを防ぎ、描画を再開する場合は新しいフォルダーのコピーを作成します。

モデルの形状の詳細では上部・中央・下部の幅と厚み、前後の輪郭、曲がり、局所的な突起を編集できます。円柱を上広・下細にしたり、口先を前へ出せます。円錐と角錐の頭部も追加されています。examples/models の TaperedCylinder・MuzzleHead・LongMuzzleHead・BarrelBody・CurvedLimbs を試してください。形状の変更は実際のメッシュとUVの適合性に影響するため、描画の前に形を決めてください。

外部のピクセル描画ソフトを使用してください。モデル表面に直接描く機能はありません。

  1. 先に形状を決め、UVテクスチャ → 描画を開始・再開から描画フォルダーを選びます。次回は前回の描画を再開で、ボタンの下に表示されたフォルダーに接続できます。画面を開くだけでは画像を読み込みません。別のフォルダーはテクスチャの詳細操作 → 描画フォルダーを切り替えから選びます。
  2. 各部位の PNG を描画ソフトで編集します。キャンバスサイズと UV の各面の位置は変更しないでください。*_Guide.png は参考画像で、差し替え用ではありません。
  3. UV_Model.json は PNG と同じ場所に残してください。ガイドの F/R/B/L/T/D は前・右・後・左・上・下です。
  4. PNG を保存するとプレビューが自動更新されます。保存途中などで読み込めない場合は、最後の正常な画像を維持します。描画フォルダーを開くボタンで素材に戻れます。
  5. 個別の画像は差し替えボタン、または部位カードへの PNG のドラッグでも変更できます。確認後に画像を適用します。キャンセルでは、この画面の未適用の変更を破棄します。

再開フォルダーはプロジェクトに埋め込まれた描画ごとに記憶します。別の描画へ切り替えても前のキャラクターのフォルダーには自動接続しません。同じ描画は記憶を共有でき、旧版からの更新時や別のPCでは一度選び直してください。パスはローカル設定だけに保存し、モデルには含めません。未描画のキャラクターは標準の記憶を共有し、接続時にはUVも検査します。

カードには、マッピングの一致、出所不明、ファイルの欠落や読み込み失敗が表示されます。一致の検査は部位、UV 配置、表面形状を比較するもので、目や服が正しい位置に描かれているかは判定しません。寸法が正しくても記録がない PNG は、出所不明として読み込めます。透明部分が似ていても一致の証拠にはなりません。

形状、長さ、厚さを変えると UV が変わる場合があります。画像は面ごとに調整されますが、描き直しが必要なこともあります。描画を続ける前に、新しい描画フォルダーへ適合させる操作で -v2、-v3 のコピーを作れます。元のフォルダーは残ります。部位の位置や関節の間隔だけの変更では、その部位の UV 配置は変わりません。

未描画の新規キャラクターでは、左右の手足の画像を共有します。描画済みサンプルでは独立している場合があります。右側カードで左側画像との共有を解除すると、現在の絵を保ったまま独立して描けます。詳細なテクスチャ操作には、ピクセル保護、セットの読み込み・書き出し、リセットがあります。

7. 小さな模様のピクセル配置を保護する

部位の詳細操作またはサムネイルからピクセル保護を開きます。小さな動きの間、相対的な配置を保ちたい模様を選びます。顔の数ピクセルなどに適しています。

  • 矩形選択またはブラシを使用します。Shift は追加、Ctrl は除外、右ボタンは一時的な消去です。
  • ホイールでポインターを中心に拡大縮小し、中ボタンまたは Space を押してドラッグすると移動できます。Fit で UV の面を表示範囲に収めます。
  • 選択したピクセルを保護する操作でグループを作ります。既存のグループも編集できます。選択中はオレンジ、保存済みはシアンです。Ctrl+Z で選択のストロークを戻せます。
  • 保護角度を設定します。超えるとグループ全体が通常の UV サンプリングに戻ります。初期値は 40° です。
  • グループを適用した後、外側の UV 画面でも画像を適用して、プロジェクトに確定します。

グループは隣接する UV 面をまたげます。ただし、他の部位による遮蔽や輪郭の外へのはみ出しは防げず、すべての角度で完全には維持できません。小さくまとまった模様を選び、回転と動作を確認してください。グループはプロジェクト・モデルの JSON と UV セットに保存されます。PNG だけには含まれません。

8. フレームを書き出す

書き出し画面で、保存先、名前、ビュー、倍率、種類を選びます。別の書き出しビューを指定していなければ、選択中のビューが初期値になります。実行前に確認してください。

  • PNG連番：透明背景の各フレーム。
  • PNG横並び画像：透明背景でフレームを横に並べた画像。
  • GIF：動作確認用。最終的なピクセル素材には PNG を推奨します。
  • JSON動作レシピ：再編集できるプロジェクト・動作データ。

1x は1フレーム 64 × 64、4x は 256 × 256、8x は 512 × 512 です。最近傍法で整数倍に拡大します。元の1ピクセルの線は、4x では出力画像の4ピクセル分になります。

同名のサブフォルダーを作る設定は初期状態でオフで、選んだ保存先に直接書き出します。前回の保存先を記憶します。同名ファイルは上書きしないため、重複した場合は名前か保存先を変更してください。処理はバックグラウンドで進むので、完了表示を待ってください。

ゲーム用の方向別素材は、同じ書き出し視点メニューで4方向（水平）／8方向（水平）を選択します。横並び画像の項目が方向別アトラスになり、各行が方向、各列がフレームになります。各方向のPNG連番・GIFも出力できます。NAME_atlas.jsonに画像・切り出し矩形・フレーム時間・再生方式・共通基準点を記録し、JSONレシピは編集可能なプロジェクトを保存します。幅4096ピクセルを超えるアトラスは自動分割し、各ページに全方向の行を保持します。既存ファイルを上書きせず、一時保存後にフレーム情報を最後に公開します。方向別アトラスの形式と、examples/atlases のTailWalk・HoverWave・FrontCrawlを参照してください。

9. 保存・共有・作業の復元

保存 / Ctrl+S は、キャラクター、画像、保護グループ、動作をプロジェクト JSON に保存します。プロジェクトを開く操作は全体を読み込みます。現在の動作を維持するモデルの読み込みとは異なります。保存した JSON を別の PC で開く際、元の PNG のパスは不要です。元画像を描き続ける場合は、描画フォルダーも別途保管してください。

examples/models は再利用する外観、examples/characters は中立ポーズの完全なキャラクタープロジェクト、examples/motions は動作レシピ、examples/UV は標準モデルのテンプレートです。形状変更後のモデルに標準 UV が合うとは限りません。

自動保存は user_data/studio3d_motion.json、UI 設定は user_data/ui_settings.json です。インストール先が書き込み不可の場合、%LOCALAPPDATA%\FellowStudio3D を使用します。インストール先を置き換える前に、自分の JSON をバックアップしてください。配布 ZIP に個人の自動保存や設定は含まれません。描画済みサンプルは意図的に同梱しています。

10. よくある問題

  • EXEが開かない：パッケージ全体を展開し直してください。EXE だけを移動しないでください。起動エラーが表示された場合は、ローカルデータフォルダーの startup-error.log を確認します。
  • 画像が読み込めない：部位、寸法、モデルとの一致を確認します。既知の不一致には適合処理が必要で、寸法が同じだけでは不十分です。
  • 回転で顔のピクセルが変わる：小さな保護グループを作り、保護角度を確認します。遮蔽と元の解像度による制約は残ります。
  • 調整の反映が遅い：物理効果の確認は計算の完了を待ちます。細かく調整するときは再生を止めてください。
  • UIが小さい：A＋ を使います。収まらない場合はパネルをスクロールするか、幅を広げてください。

追加した耳は頭部に固定して追従します。任意の外部メッシュの読み込み、任意の骨格構成、耳の独立した物理動作には現在対応していません。ソース版の準備と配布物の作成は開発ガイドを参照してください。

髪型とアニメーション

頭部（ぬいぐるみは本体）は外形・髪・耳のタブに分かれています。髪は「パーツを追加 → 追加済みパーツ → 選択したパーツの設定」の構造です。本体、左右の前髪、左右の中間髪束、後ろ髪、左右のテール、自由な髪束を個別に追加し、複製・対称コピー・削除できます。旧ファイルの自由な髪束は詳細で分類を変更でき、形や骨格は保持されます。

髪の本体には5種類の輪郭、寸法、生え際、覆い、頭頂の形状があります。髪束は14項目の造形、独立UV、3関節を保持します。左右の連動が可能で、反対側を追加すると既存の形状を対称コピーします。顔と体の描画は保持されます。

髪型テンプレートは独立した折りたたみ入口にあります。5種類から選び、置き換えを明示するとパーツを一度生成します。モデルを確定するまではキャンセルでき、確定後も取り消せます。

全体調整 → 髪で骨格・柔らかさ・反発を調整し、髪の揺れレイヤーやポーズカードも利用できます。肩・背中の衝突判定はなく、附属部品の合計上限は32です。しっぽの「尾先の太さ」で丸い猫のしっぽにでき、0では従来の形を保持します。
