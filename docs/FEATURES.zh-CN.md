更新基线：2026-10-26，v0.4.0。包含可调画幅、独立光照／自阴影、模块化头发与独立耳朵页签。

评审调整：已移除自动像素表情和重复角色；入口统一到“制作动画”，新增独立动画保存、三段尾巴控制与松软、单张UV保存和剪贴板替换。本次按用户要求统一提交Git并生成公共itch包。

## 目的与基本流程

让没有动画经验的人摆角色姿势、制作游戏像素序列帧，不要求学习关键帧、建模、绑骨或拆 UV。流程为：选择角色 → 调整形体 → 绘制外观 → 选择基础动作并局部修改／融合 → 检查与导出。

复古动画（本地开发版）：显示区一键切换约8次/秒换画节奏、独立上身保帧及相连部位像素对齐，减少微动引起的整体重采样；保留帧数和时长、接触状态和单次首尾，预览／导出一致。详见 [分析与边界](RETRO-ANIMATION.zh-CN.md)。

本地界面优化：统一项目／角色／动画／显示／导出归属，模型五个同级页签；复古动画移至动画表现，显示选项可收起；整项响应换行、部位镜像与配对、动作层排序、会话内导出配置和确认覆盖。见 [界面框架与自查](UI-DESIGN.zh-CN.md)。

小屏幕适配：主窗口启动与缩放时自动调整 UI 比例和侧栏宽度，保留中央预览；手动字号偏好与实际适配比例分开保存，不影响导出画幅。

## 边界

- 耳朵目前固定跟随身体表面，尚无独立摆动骨架或物理。
- 尾巴支持三段FK、连续蒙皮与逐节松软／回弹；尚无碰撞或自动避障，多根尾巴共用动画通道，以第一根为物理参考。
- 手持道具与一只手腕刚性连接，尚无双手约束、碰撞、抛掷或脱手轨迹；不参与接地和身体翻滚中心的计算。
- 姿势动画按关节参数插值，地面接触用于高度对齐，不自动规划脚步或避障；过渡路径可能需要调整卡片检查。
- 像素保护在角度阈值附近可能跳变；普通 UV 旋转也会改变细小图案的采样。
- 改变形体或身体结构后，贴图需要检查；适配不能保证绘画视觉完全不变。
- 猫与熊本熊布偶资源单独交付于本地角色包；不自动纳入公共案例或源码分发。
- 本地个人存档和未登记案例不属于公共功能资源，不提交或打包。

## 后续判断标准

先从具体游戏素材任务推导需求，再找现有能力无法自然完成的环节。优先复用入口、自动化重复步骤、修复反馈与性能；增加参数时明确双向范围。每轮先写最少操作步骤与兼容性，再完成围绕该场景的一组功能、内容和验证。保留用户画好的像素和旧项目。

## 头发与耳朵

- 头部／布偶主体下外形、头发、耳朵分为独立页签。头发按实际部件编辑，支持主体、左右刘海、左右中发束、后发、马尾和自由发束单独添加、复制、镜像与删除；模板只做一次生成。
- 主体五种轮廓与覆盖、顶部塑形；发束14项参数、独立UV和三节骨骼，左右同步，松软回弹、动作层和姿势卡。旧部件可重分类，保留动画编号。
- 原角色贴图和耳朵保留；无肩背碰撞，长发需检查穿插。[使用说明](HAIR.zh-CN.md)。
- 尾尖粗细0保持旧尖尾，增大后可做圆钝猫尾，保留UV与骨骼。
