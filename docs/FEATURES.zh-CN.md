# FellowStudio3D 当前功能

更新基线：2026-10-26。此表描述当前源码；已发布 v0.2.0 包不包含所有后续更新。

## 目的与基本流程

让没有动画经验的人摆角色姿势、制作游戏像素序列帧，不要求学习关键帧、建模、绑骨或拆 UV。流程为：选择角色 → 调整形体 → 绘制外观 → 选择基础动作并局部修改／融合 → 检查与导出。

## 边界

- 耳朵目前固定跟随身体表面，尚无独立摆动骨架或物理。
- 像素保护在角度阈值附近可能跳变；普通 UV 旋转也会改变细小图案的采样。
- 改变形体或身体结构后，贴图需要检查；适配不能保证绘画视觉完全不变。
- 猫与熊本熊布偶资源单独交付于本地角色包；不自动纳入公共案例或源码分发。
- 本地个人存档和未登记案例不属于公共功能资源，不提交或打包。

## 后续判断标准

先从具体游戏素材任务推导需求，再找现有能力无法自然完成的环节。优先复用入口、自动化重复步骤、修复反馈与性能；增加参数时明确双向范围。每轮先写最少操作步骤与兼容性，再实现一项可验证的改进。保留用户画好的像素和旧项目。
