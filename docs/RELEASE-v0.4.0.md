# FellowStudio3D v0.4.0

- Adjustable canvas sizes for larger characters.
- Pixel-style lighting and self-shadows with separate controls.
- Modular hair with detailed shaping, mirrored editing, and reusable templates.
- Independent hair bones, motion blending, and soft follow-through.
- Cleaner Head, Hair, and Ears tabs.
- Rounded tail tips and updated custom character defaults.

## Windows download

Upload `FellowStudio3D-v0.4.0-itch-Windows-x64.zip` as a Windows downloadable application. Extract everything and run `FellowStudio3D.exe`; no Python installation is required. The flat archive includes itch app launch actions, an offline runtime, three-language manuals, licenses and SHA256 hashes. Personal mascot models, local sessions and unregistered examples are excluded.
