# 本地评审调整：角色、尾巴、物品与动画复用

本页记录本地评审结果。2026-10-26用户确认后，将已验收的改动统一提交Git并制作v0.3.0公共itch包；此前评审阶段没有提交。早间迭代报告与体验说明是历史快照，当前行为以本页及已更新手册为准。公共包不包含熊本熊、猫咪和个人存档。

## 本轮调整

- **单张UV操作**：点击部位贴图打开窗口，顶部“保存 PNG…”保存原尺寸透明贴图；“复制贴图（Ctrl+C）”复制原图，“粘贴替换（Ctrl+V）”从系统剪贴板替换当前部位。尺寸必须匹配，不自动缩放；保留保护组，网格、选区和参考线不写入图片。替换先在窗口内暂存，可撤销；“应用贴图”后更新外层编辑器，“取消”放弃。旧绘画文件不会覆盖粘贴结果；继续绘画时为新贴图创建副本。

- **尾巴**：改成尾根／尾中／尾尖三个独立FK关节与连续蒙皮。模型窗口设置外形；主窗口“整体控制 → 尾巴”调整各节旋转，也可拖动四视图圆形关节。下方“物理跟随”提供尾根／尾中／尾尖松软和回弹，默认0；可从0.2／0.45／0.65开始，让尾尖更松软。添加“尾巴摆动”作为普通动作层，支持比例、时段、淡入淡出和融合；姿势卡保存尾巴姿势，松软设置随项目及独立动画保存。预览与导出使用同一确定性模拟，尚无碰撞。
- **表情**：移除自动像素表情、眨眼、说话及相关角色。旧模型中的表情参数会忽略，原内嵌PNG保持原样；不自动重绘五官。
- **手持物品**：改成长方体、圆柱体、球体、圆锥体四种可编辑形状，可以用于包裹、杯子、工具等。保留独立UV、尺寸与握持调整。旧武器模型兼容读取，不再作为默认入口或案例。
- **角色库**：默认保留默认角色、彩绘角色、一体布偶三种起点。撤下九个重复的尾巴／装备／表情变体，原文件保留于本地`.audit/retired-placeholders-20261026`。本地角色库直接加入之前完整绘画的熊本熊、猫咪，原模型和PNG不重画。
- **动画存储**：“制作动画… → 保存动画…”保存独立动作JSON，包含组合、姿势卡、尾巴、控制器与物理，不包含角色外观。默认存入`user_data/motions`，并出现在“创作资源库 → 动作 → 我的动画”。给另一个角色应用时保留它的模型、贴图和显示设置。顶部“保存”仍保存完整项目。
- **界面**：“从姿势开始／姿势动画／动作串联／保存动画”统一放进“制作动画”；取消重复快速搭配页。串联窗口扩大为固定双栏，左侧顺序和时间安排、右侧设置、底部固定生成／取消，避免操作按钮换行。

## 熊本熊与本地体验包

源码运行时读取已有`user_data/models/KumamonBag.json`与`CatBag.json`；本地个人体验包把它们放在`local_characters`供角色库读取。公共构建默认不带个人角色，只有明确使用`--personal`才加入这两份已指定的完整模型，不复制其他个人存档或实验模型。

原来的[猫与熊本熊绘画资源包](../../../PlushCharacters.zip)不改写。新角色绘画研究参考了[卡比官方形象](https://www.kirby.jp/character/kirby/)和[哆啦A梦官方角色页](https://www.tv-asahi.co.jp/doraemon/character/)；卡比固定贴图的图像生成请求被服务拦截，没有把未完成占位角色加进库。后续新增角色按少量完整绘画与多视角验收推进。

## 验证重点

检查三关节层级、蒙皮闭合、控制器与动作融合、UV不随动画重新排布、像素保护、保存与跨角色迁移；检查旧表情参数不改变原画、四类物品闭合及旧文件读取；检查熊本熊原PNG与库内显示一致，并在0.85／1.5／2倍缩放下检查串联窗口。

模型比例不同会影响动作的落脚、握持和穿插，迁移动画后仍需播放检查；当前没有自动重定向比例或碰撞规划。
