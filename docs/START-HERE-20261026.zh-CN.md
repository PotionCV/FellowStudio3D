# FellowStudio3D：本次迭代体验入口

本次更新将原本的摆姿势与动作融合，扩展为角色造型、表演编排、外观表现和游戏序列帧导出的完整流程。保留真实3D、64×64原生像素、1px描边、四视图、整数倍输出和可携带绘画。此文对应2026-10-26源码与本次本地体验包，早先发布的v0.2.0不包含全部功能。

## 先做出第一段动画

1. 完整解压Windows体验包，双击`FellowStudio3D.exe`，保留旁边的`runtime`目录。
2. 打开**创作资源库… → 快速搭配**，试试猫咪游泳、空中施法或聊天迎宾。
3. 点**播放**检查四视图。切到角色或动作页签，可以只换其中一项；完成预览后**应用搭配**。
4. **角色模型**调整形体、装备或表情；**姿势动画…**摆自己的姿势卡；**动作串联…**安排连续动作。
5. 保存项目JSON。导出选择**四／八方向**与PNG／图集／GIF；先用**1×**检查原生像素。

## 想做什么，从哪里进入

| 创作目标 | 入口与做法 |
| --- | --- |
| 找角色、试动作 | 创作资源库；49个动作、19个角色，支持三语名称、文件名、关键词与分类 |
| 猫咪或袋状布偶 | 角色模型 → 身体结构 → 一体布偶；主体五项尺寸，耳朵和尾巴继续独立编辑 |
| 自己编一段表演 | 姿势动画；2～6张姿势卡，采集当前动作帧、拖动手脚、镜像、停留与过渡 |
| 多步游戏动作 | 动作串联；最多六步，调整顺序、帧数和过渡，生成后仍可编辑动作层 |
| 游泳或空中漂浮 | 基础动作选择游泳／悬浮，或从资源库选择蛙泳、自由泳、踩水、悬浮招手等 |
| 剑盾、双剑或法杖 | 角色模型 → 左臂／右臂 → 手持道具；常用尺寸与握持，更多位置和角度按需展开 |
| 眨眼、说话或惊讶 | 角色模型 → 像素表情；五种表情，可关闭恢复原画，也可将当前帧转为绘画贴图 |
| 绘制角色外观 | UV贴图 → 开始／继续绘制；在外部像素软件保存PNG，预览自动刷新，再应用贴图 |
| 游戏多方向素材 | 导出视图 → 四／八方向；图集和JSON帧信息包含矩形、时长、锚点与分页 |

## 三条建议体验路线

- **猫咪游泳**：选快速搭配“猫咪游泳”，进入角色模型调尾巴弯曲，回到基础动作切换蛙泳／自由泳，保存并导出四方向。
- **装备角色表演**：选“空中施法”或“双剑舞步”，调握持，添加头部动作；想重新编排时打开姿势动画，采集喜欢的帧再继续修改。
- **有表情的聊天布偶**：选“聊天迎宾”，在像素表情里改开心／生气、眨眼与说话次数；要手绘眼口时转为绘画贴图，再准备新的绘画副本。

各编辑窗口在应用前可取消；主项目的应用操作可撤销。保存JSON会包含角色、绘画、像素保护和动作。绘画目录按内嵌绘画分别记忆，目录路径留在本机设置；不同贴图的角色不会自动接上前一个绘画目录。完全相同绘画共享记忆，旧版升级后可重新选一次。

## 已知边界与后续方向

- 动作串联按普通动作层过渡；姿势卡按关节参数插值。尚无连续连招重心规划、锁脚步伐或自动避障，需播放检查滑步与穿插。
- 耳朵跟随表面，尾巴整根摆动，单手道具刚性握持；尚无分节物理、双手约束、碰撞或抛掷。
- 像素表情是前侧UV的覆盖层，不识别已有手绘眼口，不做语音同步；复杂底色可自行指定。
- 大幅动作和长装备需要检查构图；四／八方向导出不会自动重新取景。画幅保持64×64，放大仅使用整数像素。
- 资源库只索引登记的公共案例，个人文件通过显式载入。个人存档、未登记案例和猫／熊本熊绘画资源不放入公共体验包。
