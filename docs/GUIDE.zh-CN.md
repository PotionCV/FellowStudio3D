# FellowStudio3D 使用说明

[English](GUIDE.en.html) · [简体中文](GUIDE.zh-CN.html) · [日本語](GUIDE.ja.html) · [项目 README](../README.md)

## 1. 启动与试用角色

完整解压 Windows 便携包，双击 **FellowStudio3D.exe**。不需要安装 Python。EXE、runtime 和其他文件必须放在一起；BAT 是备用启动入口。这个便携包适用于 Windows，不能直接在 macOS 上运行。

右上角可切换英文、简体中文、日文，选择会保存。**A− / A＋** 调整界面大小。左右面板可以滚动，也可以拖动分隔条调整宽度。点击**使用说明**或按 **F1** 可离线阅读本说明。

自动生成的项目名称固定使用英文（Idle、Walk、Run），不会随界面语言翻译；自己输入的名称会保留。

第一次可以这样试用：

1. 打开**角色模型 → 载入模型**，选择 `examples/models/CustomModel.json`。
2. 点击**应用模型**，把附带的绘画角色应用到当前动画。
3. 选择**走路**或**跑步**，播放预览。
4. 点击一个视窗设为焦点，然后用 **1x** 导出 PNG 横向条带。

`DefaultModel.json` 可恢复默认外观。新用户初次启动看到的是默认小人，不会载入开发者的个人工作状态。

## 2. 不用关键帧的姿势和动画

先在左侧选择**基础动作**或预设姿势，点击编辑基础动作，调整步幅、摆臂和其他参数。动画时长、帧率和循环次数共同决定输出序列。

选择身体部位，可以整体调整它在动画中的姿势。先选双臂、双腿做整体调整，再选单侧微调。**摆动幅度**围绕动作的平均姿势调整，不是简单地把所有角度乘大。

添加叠加动作后，调整混合比例；比例为零时，这层没有影响。举手、挥手还可以设置**保留原摆动**。例如在跑步上叠加右臂举起，再调混合比例和保留原摆动，就能让手臂保持抬起，同时保留跑动的摆动。叠加动作可以启用或关闭，并选择适用的身体范围。

切换基础动作会恢复该动作的默认参数，但保留模型、贴图和显示设置。想保留某套调整，请先保存项目。**撤销 / Ctrl+Z** 可撤销编辑，**Ctrl+Y** 重做。

## 3. 头部、躯干、IK与物理跟随

适合双向调整的方向参数现已支持负值：弯腰可变为后仰，点头和摇头可反向，举手可向后，屈肘和双手间距可反向，摆臂、跨步扭转和攻击身体带动也可反向。整体控制里的“摆动幅度”小于 0 时围绕平均姿态反向摆动；新增“前后屈伸”可独立调整肘膝。“下蹲 → 双腿开合”正值外展、负值内收，0 保留原蹲姿。可试用 `examples/motions/game/LeanBack.json` 和 `WideSquat.json`。时间、次数、实体尺寸与物理松软强度仍保留各自的有效范围。

默认刺拳采用小幅身体发力：蓄力时肩部约反转 10°，出拳时转肩约 22°、转胯约 10°。这些角度是相对原有架势的变化，不是摄影机朝向。需要刻意大幅转身时，可增大“身体带动”或叠加“扭腰回正”。

刺击与挥击分别提供**蓄力幅度**和**蓄力时间**：先收拳、屈肘后撤，并向攻击反方向转动胸腔和骨盆，再打出并回到原来的架势。蓄力幅度设为 0 可取消准备动作，时间单独控制准备节奏。两种攻击都会从调整后的战斗站姿开始，不会在出拳后再次叠加架势偏移。

**扭腰回正**会带动胸腔和骨盆，再回到原始姿态。角度可正可负，“骨盆跟随”控制胯部跟转的比例，可叠加在战斗站姿或攻击上。刺击、挥击、踢击的“身体带动”加强并扩展至 0–3，新添加的攻击默认作用于“相关部位”，包含骨盆转动；明确选择手臂或腿部遮罩仍会限制作用范围。旧的攻击层需要将“作用部位”改为“相关部位”，才能使用完整带动。

**举手 → 举手方向 → 向前**支持向前伸手、捧物和高举，可分别调高度与屈肘。选择“向两侧”可使用原来的侧向举手，已有配方仍保持原方向。

**取放物品**先向下够取，再举起并保持持物姿势；选择“放回地面”会反向完成这一过程。支持左右手和双手，可调弯腰、下蹲、双手间距、举起高度和屈肘。举起高度可达 180°，高举时手肘会自动逐渐伸直。长手臂、短腿模型会自动减少过量弯腰下蹲，避免手碰地后把脚顶离地面。这个动作只控制角色，不会自动添加物品模型。使用“保持末帧”可保留最后的持物姿势。示例位于 `examples/motions/`：`game/Pickup.json`、`game/PutDown.json`、`game/LiftOverhead.json`、`fusions/CombatTwist.json`、`fusions/CombatPushKick.json` 和 `fusions/ForwardCarry.json`。

Kick 增加“踢腿方式”：**摆踢**保留原来的动作；**踹腿**先提膝，再向前蹬直，随后收腿落下。两种方式都支持左右腿、双腿和时间调整。可载入 `examples/motions/game/PushKick.json`，也可在跳跃的踢击融合层中选择踹腿。

跳跃或弹跳腾空时，普通姿势和动作层会继承腾空状态、保留跳跃高度；替换和姿态融合也一样。踢击、受击、倒地、转身或带接地提示的姿势不会把角色拉回地面，动作层放在跳跃层前面也支持。明确选择“地面翻滚”仍会强制接地。`examples/motions/fusions/JumpKick.json` 提供空中踢腿示例。

刺击会从调整好的防守姿势准备、伸臂出拳，再收回同一防守姿势。手臂姿势控制先应用，不会在出拳后再次叠加防守的弯肘。出拳伸展时手臂会收紧，收拳阶段恢复普通物理跟随。可以载入 `examples/motions/fusions/CombatStraightPunch.json`，或直接给 CombatStance 添加刺击。

站姿呼吸会通过腿部 IK 轻微屈膝、回弹，让双脚保持位置；叠加上半身姿势或腿部松软时也会维持脚部锁定。关闭**调整身体时保持脚的位置**可允许脚自由移动。呼吸不会把跳跃中腾空的脚强制拉回地面。

制作稍微侧身的战斗姿态时，先选躯干，用**整体朝向**按 1° 微调全身方向，再分别调整胸腔转向与骨盆转向。骨盆只影响下躯干和腿根，因此小角度在 64px 下可能不明显。`examples/motions/fusions/CombatStance.json` 提供一个保留呼吸、胸胯错开、头部朝前的防守站姿。

在预览下方输入**总帧数**（1–120），按回车或移开焦点即可生效。它是整个序列的帧数。**FPS** 决定播放速度：24 帧、12 FPS 就是 2 秒。修改 FPS 会保留总帧数；基础动作的重复次数决定这段序列里做几轮动作。

预览上方的**画幅 Y（px）**按原始像素整格偏移构图：正值让角色下移，负值上移。四个视图、IK 手柄和导出都会同步，切换动画时保留，随项目保存。它不会改变角色在世界中的位置；如果角色比画幅本身还高，仅靠上下移动仍然放不下。

**显示贴图**和**部位分色**是独立开关：关闭贴图可以查看分色素模；两者都关则显示白模。关闭分色仍会保留绘制的贴图。显示选择会记住。新叠加层默认使用**叠加变化**，已有明确设置的融合方式会保留。**开始位置／结束位置**表示整段动画的绝对位置，范围 0–1，结束位置必须晚于开始位置。

空中翻滚可以组合跑步、跳跃和翻滚。翻滚的**跟随基础动作**会保留跳跃的腾空轨迹；地面翻滚会强制贴地，空中翻滚则关闭贴地。把翻滚的开始／结束位置设在腾空阶段即可。`examples/motions/fusions/RunJumpRoll.json` 提供示例，画幅 Y 为 8；如果你已设置构图，载入动作案例会保留当前值。单次动画的物理脱力会跟随父骨骼在世界空间中的旋转，查看时请播放动作中间的帧，播放到末帧后会停止。

**播放方式**可选循环、播放一次、保持末帧。非循环动作包含完整末帧并在末尾停止，GIF 也只播放一次。倒地默认保持躺姿，起身结束于站姿；物理跟随不会用结尾反复预热开头。

**动作案例…**载入可编辑配方，保留当前模型、贴图和显示设置。`game` 包含起跳与落地、刺击、挥击、踢击、受击、倒地、起身、翻滚、攀爬循环和原地转身。攻击可调蓄力和发力时间，跳跃可调准备、腾空和落地。受击恢复程度设为零可保持受力姿势。走跑的移动方向可制作侧移或后退，脚步间距和支撑时间也可单独调整。

添加**姿势层**会获取当前帧姿势。可载入 `examples/poses` 中的 Carry、Aim、Guard、Crouch，或保存自己的姿势。选择作用部位、影响比例和保留原摆动。挥手与攻击支持左侧、右侧、双侧，以及同步或交替。在**时间与融合设置**里设置开始位置、结束位置、淡入淡出与融合方式：姿态与摆动修改姿态中心并保留原摆动；替换选中部位跟随新动作；叠加变化添加相对站姿的改动。播放一次的层在区间后退出，保持末帧的层会延续末姿势。短动作优先选替换，并在导出前检查衔接。`fusions` 提供搬物、持盾、瞄准和跑步中短暂挥击等组合。载入案例会替换当前动作，请先保存想保留的组合。

在**头颈**中，低头抬头、左右转头、歪头、前后位置可以独立调整。关闭**跟随胸腔转动**，头部就不再继承胸腔的左右扭转。走路和跑步还提供**跨步扭转**，控制胸腔与骨盆的反向转动。

躯干可调整弯腰、身体高低、侧倾、胸腔转向、骨盆转向。开启**调整身体时保持脚的位置**，腿部会在可达范围内通过 IK 保持脚的位置。暂停后，可以拖动显示出的 IK 手柄调整四肢。拖不到预期位置时，检查肢体长度或减小位移。**翻转肘 / 膝弯向**可改变单侧弯曲方向。

**上段松软**和**下段松软**分别控制物理跟随。建议从小数值开始，过强可能盖过原来的动作。调参后，预览可能先显示直接姿势，再补齐物理模拟与其他帧；判断完整效果前，请等待计算结束。

## 4. 视角与像素显示

点击四视图中的一个设为焦点。正面、侧面是正交视角；斜面是水平斜视，斜俯才增加俯视角度。模型与 UV 窗口可开启**单视图**，也可双击视窗放大。按住**查看修改前**，可与打开编辑器时的外观比较。

原始画布为 **64 × 64 像素**。预览放大不会增加绘画精度。边线固定为原始图像的 **1像素**，可选边线颜色或自动灰色。部位分色、交叠留缝、外边线是独立显示选项。实体相接或穿入的地方会抑制内部线，前景部位真正遮住后方部位时可以保留分界。

## 5. 调整角色模型

打开**角色模型**，选择部位与基础形状，再调整比例。头部支持椭圆、圆柱、圆角方形、方形，躯干与四肢也有多种形状。开启**左右联动**可一起修改左右肢体。

肩宽、腰宽、胯宽改变正面轮廓。**躯干厚度**改变前后厚度，同时影响胸腹和胯部；略壮的体型可先试 **1.15～1.3**。新建模型默认 1.15，旧模型保持原厚度。还可以调整头部间距与前后位置、四肢长度、关节偏移和接合间距。负偏移向内或重叠，正偏移向外或分离。胯部覆盖用于填补两条腿根之间的区域。

编辑先在窗口内预览，点击**应用模型**才写入项目，**取消**放弃未应用的修改。**保存模型**会把形体、内嵌贴图和像素保护组一起保存成可复用 JSON。载入模型只替换外观，保留当前动画；旧版只含形体的预设会保留当前贴图。

**头颈 → 附属部件**可添加人耳、猫耳、长耳，默认左右成对。选择耳朵，展开**编辑耳朵参数**可调左右、上下、前后位置，以及耳根宽度、长度、厚度、耳尖宽度和三个旋转角度。位置相对塑形后的头部，尺寸使用原始像素。关闭**左右联动**可独立修改，也可删除一只或一对。耳朵固定跟随头部动画。**应用模型**后，UV 窗口增加耳朵卡片，右耳默认共用左耳贴图；关闭共用即可独立绘制。模型与项目会一起保存耳朵、贴图和保护组。旧绘画文件夹没有耳朵模板时，使用“适配到新绘画文件夹”生成新 PNG。

选择**身体结构 → 一体布偶**，头颈和躯干会合并成**主体**面板，只保留整体高度、上部宽度、肚子宽度、底部宽度和主体厚度五项常用参数。外形从头顶到肚子连续，没有脖子接缝；四肢和耳朵仍可独立调整。默认开启**头身一起动**，关闭后可用头部动作柔和地转动上部，并调整柔和程度。胸胯旋转、四肢、IK 和原有动作继续可用。UV 窗口将头与躯干两张卡片替换成一张主体卡片，保存模型会一起保存主体参数、贴图和保护组。切换结构会改变主体 UV，请为新结构建立新的绘画文件夹。`examples/models/PlushModel.json` 可作为未绘制的起始模型，旧分体模型的外形和 UV 保持原样。

## 6. 绘画与替换贴图

在**角色模型 → 展开塑形参数**中，截面比例可分别调整顶部、中部、底部宽度和厚度；前后轮廓可调前后各段与中段弯曲；局部凸起可制作凸出的脸或口鼻。圆柱的上宽下窄会改变真实网格，头部也增加圆锥与角锥。可以载入 `examples/models` 中的 TaperedCylinder、MuzzleHead、LongMuzzleHead、BarrelBody、CurvedLimbs 体验。先确定外形再绘画，修改外形后的自动适配仍可能需要修图。

贴图需要在外部像素绘画软件中绘制，目前不能直接在模型表面画画。

1. 先调整形体，再打开 **UV贴图 → 开始 / 继续绘制**，选择绘画文件夹。
2. 在绘画软件中修改各部位 PNG，不改变图片尺寸和各 UV 面的位置。`*_Guide.png` 是参考图，不要把它当作正式贴图替换。
3. 保留同目录的 `UV_Model.json`。参考图上的 F/R/B/L/T/D 分别是前/右/后/左/上/下。
4. 保存 PNG 后预览会自动刷新；保存过程中短暂损坏或不完整的图片不会替换上一次正确贴图。**打开绘画文件夹**可返回素材位置。
5. 单个部位可点击**换图**或把 PNG 拖到卡片上替换。检查预览后点击**应用贴图**；取消放弃本次未应用的编辑。

卡片会提示布局是否匹配、来源未知、文件缺失或无法读取。匹配检查核对的是部位、UV布局和表面形状，不能判断五官或衣服是否画对位置。没有可靠记录但尺寸符合的 PNG 可以导入，会标为**来源未知**。透明区域相似并不能证明匹配。

改变形状、长度、厚度可能改变 UV。原有贴图会按面自动适配，但图案可能需要重画。继续绘画前，可用**适配到新绘画文件夹**生成带 `-v2`、`-v3` 后缀的新副本，旧文件夹保留。单纯改变部位位置或关节间距不会改变该部位的 UV 布局。

新建未绘画角色默认共用左右肢体贴图；绘画案例可能保持左右独立。在右侧肢体卡片关闭**共用左侧贴图**即可独立画，解除共用会保留当前图案。**高级贴图操作**中还有像素保护、整套导入导出和恢复功能。

## 7. 保护小图案的像素排列

从部位的高级操作或缩略图进入**像素保护**。选中希望在小幅运动中保持相对排列的图案，例如几个五官像素。

- 使用框选或画笔；Shift 加选，Ctrl 减选，右键临时擦除选区。
- 滚轮围绕鼠标缩放，中键或空格拖动平移；Fit 可聚焦 UV 面。
- 点击**保护所选像素**创建组，也可以选择已有组编辑。当前选区为橙色，已保存组为青色。Ctrl+Z 撤销选区笔画。
- 设置**保护角度**，超过角度后整组恢复普通 UV 采样。默认是 40°。
- 先点击**应用保护组**，再在外层 UV 窗口点击**应用贴图**，才写入当前项目。

同一组可以跨相邻 UV 面。保护不改变部位遮挡，也不会把轮廓外的像素强行显示出来，不能保证任意角度无损。尽量保护小而连贯的图案，并检查旋转和动画。保护组保存在项目、模型 JSON 和 UV 包中，单独一张 PNG 不包含保护组。

## 8. 导出序列帧

打开**导出序列帧**，选择目录、名称、视角、倍率和类型。如果之前没有指定其他导出视角，初始选择是焦点视图；导出前请确认。

- **PNG序列**：每帧独立透明图片。
- **PNG横向条带**：多帧横向排列的透明图片。
- **GIF**：动画预览，正式像素素材建议使用 PNG。
- **JSON动作配方**：可以继续编辑的项目与动画资源。

**1x** 每帧为 64 × 64，**4x** 为 256 × 256，**8x** 为 512 × 512，只使用最近邻整数倍放大。原始1像素边线在4x图片中占4个输出像素。

**创建同名子文件夹**默认关闭，文件直接导出到所选目录。上次目录会记住。同名输出文件不会被覆盖，冲突时请改名称或目录。导出在后台进行，请等完成提示后再使用文件。

## 9. 保存、分享与恢复

**保存 / Ctrl+S** 将角色、贴图、保护组、动画一起写入项目 JSON。**打开**会载入完整项目；与保留当前动画的“载入模型”不同。把项目分享给别人时，不需要附带原贴图路径；如果还要继续绘画，请自行保留绘画文件夹。

案例按用途放置：`examples/models` 是可复用外观，`examples/characters` 是中立姿势的完整角色项目，`examples/motions` 是动作配方，`examples/UV` 是默认模型模板。默认 UV 模板不一定适合改过外形的模型。

自动恢复文件是 `user_data/studio3d_motion.json`，界面偏好是 `user_data/ui_settings.json`。工具目录不能写入时，会回退到 `%LOCALAPPDATA%\FellowStudio3D`。替换安装目录前请备份自己的项目 JSON。发布包不包含个人自动存档和偏好；绘画案例是专门随包提供的。

## 10. 常见问题

- **EXE打不开**：重新完整解压，不要只移动 EXE。如果提示启动错误，请查看本地数据目录中的 `startup-error.log`。
- **贴图无法载入**：检查部位、图片尺寸和模型是否匹配；已知不兼容的文件需要适配，尺寸相同还不够。
- **转动时五官变化**：为小图案建立保护组，检查保护角度；部位遮挡与原始像素分辨率仍会影响显示。
- **调参后反应慢**：等待本轮计算结束后再判断物理效果；精调时可以暂停播放。
- **界面太小**：点击 A＋；控件放不下时滚动面板或拖宽面板。

目前附属部件支持固定跟随头部的耳朵，尚不支持任意外部网格导入、新增骨骼或耳朵独立物理运动。源码安装与发布构建见[开发说明](DEVELOPMENT.md)。
