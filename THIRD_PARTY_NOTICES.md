# Third-party components

FellowStudio3D uses NumPy, Pillow, Tk/Tcl, tkinterdnd2 (including TkDND), and
the Boutique Bitmap font. Their licenses remain with their authors.

- Font: BoutiqueBitmap9x9, 2020–2022 Cen-cyun Liu / Luke Liu, with component
  notices in `Boutique9_OFL.txt`. Distribute that file with both font files.
- Python and Tk/Tcl: the portable archive includes the interpreter's LICENSE
  and the Tcl/Tk license files from the runtime installation.
- NumPy, Pillow and tkinterdnd2: the portable builder copies the installed
  distribution metadata, license files and bundled native-library notices.

The source archive does not bundle Python or third-party Python packages.
FellowStudio3D is distributed under the MIT License in `LICENSE`.
Third-party components retain the licenses listed above.
